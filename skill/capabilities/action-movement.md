# Action and Movement Capability

Status: `FORMALIZED_PRODUCTION_CANDIDATE`.

Load when movement, interaction, pursuit, impact, transformation, or action result drives the Scene.

- Decompose only causally necessary preparation/start, interaction, result, and required reaction/recovery.
- Keep direction, target, contact point, path, phase, and end state consistent across cuts.
- A cut inside one action continues the same phase; never repeat start or impact unless scripted.
- Show both cause and visible result of consequential interaction.
- For long movement, expose meaningful waypoints and arrival state; do not imply unsupported teleportation.
- Choose static, pan, or track from readability. Pan changes view from a fixed position; track changes camera position and requires a viable path and stop condition.
- Non-realistic movement and VFX obey the same subject, target, cause, result, and continuity rules.

Does not own genre lore, ability names, full camera geometry, or model VFX wording.
